# Jarwin AI — User Guide

## Getting Started

1. Visit [jarwin-ai.streamlit.app](https://jarwin-ai.streamlit.app)
2. Choose **Chat Mode** or **Quick Mode**
3. Provide company details
4. Get your architecture blueprint
